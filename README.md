# fleet-move-probe

A throwaway repository for testing `./mac sessions move` between Ari's Macs (the agent-capacity/mac-mini-work-machine-setup desk task). Probe sessions work in worktrees of this repository on `probe/*` branches. A move carries their unfinished bytes as `wip/move-*` branches. The `probe` workflow gives a move an active CI run to carry. Nothing here is product code.
